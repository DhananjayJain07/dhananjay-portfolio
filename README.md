# Dhananjay Jain — Developer Portfolio

A lightweight, responsive portfolio presenting my professional background in backend engineering, cloud-native applications, and DevOps.

## Built with
- Semantic HTML
- CSS with responsive layouts and reduced-motion support
- Vanilla JavaScript
- GitHub Actions and GitHub Pages

## Run locally
No build tools are required. Open `index.html` in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment
The workflow at `.github/workflows/deploy.yml` deploys the repository contents to GitHub Pages on every push to `main` and can also be run manually from the Actions tab.

In repository settings, open **Settings → Pages** and ensure the publishing source is set to **GitHub Actions**. The workflow needs Pages deployment permission.

Live URL after a successful deployment:
https://dhananjayjain07.github.io/dhananjay-portfolio/

## Personalize before sharing widely
- Add verified LinkedIn URL and contact email.
- Add a current resume PDF and connect the download button if desired.
- Add education details only when verified.
- Update project cards when personal demos are actually implemented; planned projects are marked clearly.
- Confirm certification details and add a credential URL if available.

## Accuracy and confidentiality
Employer projects are described at a high level. Do not publish confidential source code, diagrams, client data, or internal architecture. Project cards are labelled as planned personal work rather than completed projects.
